# 폭스러닝센터 — 오늘의 활동

학생들이 센터에 도착해 플래너를 쓸 때 보는 화면입니다. [폭스러닝센터 OS 시트](https://docs.google.com/spreadsheets/d/1Q1F7Hda6fglcwuvLKCP9S3Xf2PiwQHyp9p1iCekI2Mg/edit)의 `활동 내용` 탭에서 **오늘 칸만** 읽어 연구소별 카드로 보여 주고, 1분마다 시트를 다시 읽습니다.

## 파일 구성

- `index.html` — 학생용 화면
- `schedule.gs` — 시트에서 오늘 내용을 꺼내 주는 Google Apps Script
- `images/` — 여우 그림

## 설정 (최초 1회)

### 1. Apps Script 배포

1. 폭스러닝센터 OS 시트에서 `확장 프로그램 → Apps Script` 열기
2. 새 스크립트 파일을 만들고 `schedule.gs` 전체를 붙여넣기 → 저장
   (이미 `doGet` 이 있는 프로젝트라면, 별도의 새 Apps Script 프로젝트에 붙여넣으세요)
3. `배포 → 새 배포 → 웹 앱` — 실행: **나**, 액세스 권한: **모든 사용자**
4. 나온 웹 앱 URL(`…/exec`) 복사

### 2. 화면에 주소 연결

- `index.html` 의 `DEFAULT_API_URL = ''` 에 위 URL을 넣고 커밋 (모든 기기에 적용), 또는
- 화면에 처음 뜨는 입력칸에 붙여넣기 (그 기기에만 저장됨)

### 3. GitHub Pages 배포

저장소 `Settings → Pages` 에서 Source 를 **Deploy from a branch**, Branch 를 `main` / `/ (root)` 로 저장합니다.
1~2분 뒤 https://sean1290.github.io/foxlc-schedule/ 로 접속할 수 있고, `main` 에 푸시할 때마다 자동 반영됩니다.
(무료 요금제에서는 저장소가 공개(Public)여야 GitHub Pages 를 쓸 수 있습니다.)

## 화면 기능

- 연구소별 카드: 제목, 시간칸(시간 + 참여 학생), 설명
- 지금 진행 중인 시간칸은 "지금", 지난 시간칸은 "끝"으로 표시
- 위쪽에서 자기 이름을 누르면 "○○의 오늘"이 시간순으로 정리됨 (90초 뒤 자동 해제)
- `가−` / `가+` 로 글자 크기 조절 (기기에 저장), 핀치 줌·브라우저 확대/축소 가능
- 다른 날짜 미리보기: 주소 뒤에 `?date=2026-11-14`

## 시트 작성 규칙 (화면이 읽는 방식)

- 날짜 줄(`11월 13일(금)`) 아래로 **제목 줄 + 설명 줄**이 한 쌍씩 이어집니다. A열이 연구소 이름입니다.
- 설명 칸에서 `15:30 ~ 17:00` 같은 시간 줄과, 그 바로 아래(또는 같은 줄)의 `이름, 이름` 은 시간칸으로 표시됩니다.
- 나머지 글은 설명으로 표시됩니다.
